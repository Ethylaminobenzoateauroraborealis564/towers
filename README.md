# 🏯 towers - Watch majestic towers rise in seconds

## 🚀 Getting Started

Welcome to **towers**! This is a simple, beautiful application that creates stunning 3D towers right in your web browser. No programming or technical skills needed—just download and run.

## 📦 What You Get

towers is a single self-contained HTML file that generates three different types of traditional Asian towers:
- **Japanese tenshu** - Classic Japanese castle tower
- **Chinese pagoda** – Elegant multi-tiered pagoda
- **Thai prang** – Distinctive Thai-style spire

Each tower builds itself from the ground up in just 4.5 seconds, creating a mesmerizing generative art experience.

## ⚡ System Requirements

towers runs in any modern web browser. Minimum requirements:
- **Windows 10, 11** (or any OS with a modern browser)
- **Web browser**: Chrome, Firefox, Edge, or Safari (latest version recommended)
- **Hardware**: Any computer that can run a modern web browser
- **No installation needed**: Runs entirely in your browser
